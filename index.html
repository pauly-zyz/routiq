04 · Build

Best-price swaps in a few lines.

Wallets, dApps and AI agents will plug into the same router. One quote call, one swap call.

  • TypeScript SDK for dApps and wallets
  • MCP skill so agents can trade on your behalf
  • REST API for bots and dashboards
API preview 
import { Routiq } from "@routiq/sdk";

const routiq = new Routiq({ chainId: 4663 });

const quote = await routiq.quote({
  sell: "USDG", buy: "TSLA", amount: "2500",
});
// quote.route → [{ venue: "uniswap", share: 0.62 }, …]

await routiq.swap(quote, { signer, slippageBps: 30 });
// Add ROUTIQ to your agent's MCP config
{
  "mcpServers": {
    "routiq": {
      "url": "$ROUTIQ_MCP_URL"
    }
  }
}

// Then just ask:
// "Buy $500 of NVDA with USDG at the best price."
curl -X POST $ROUTIQ_API/v1/quote \
  -H "content-type: application/json" \
  -d '{"sell":"USDG","buy":"TSLA","amount":"2500"}'

# → { "out": "…", "impactBps": 4,
#     "route": [{ "venue": "uniswap", "share": 0.62 }, …] }

06 · FAQ

Questions, answered.

Still curious? Ask in our community channels.

What is ROUTIQ?

A smart order router for Robinhood Chain. It compares prices across the chain's trading venues and splits your order to get the best overall price in one transaction.

Is the swap preview real?

Not yet. The preview uses demo prices to show how routing works. Real quotes arrive with the router beta (Phase 2).

Which network does it run on?

Robinhood Chain mainnet — an Ethereum Layer 2 built on Arbitrum Orbit. Chain ID 4663, gas is paid in ETH.

Which wallets work?

Any browser wallet that supports the standard Ethereum provider, such as MetaMask, Rabby or Robinhood Wallet. ROUTIQ adds Robinhood Chain for you.

Can everyone trade stock tokens?

Eligibility is set by the token issuer and depends on where you live. ROUTIQ only routes assets your wallet is allowed to hold and does not bypass those rules.

Is there a ROUTIQ token?

The official contract address is published only on this site and our official accounts. Never trust addresses sent in DMs.
